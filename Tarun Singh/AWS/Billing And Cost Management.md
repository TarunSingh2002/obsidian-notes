### How To Create Budgets
- It will alert us when our account pass a certain amount. 
- Creating a budget => Billing and cost management -> Budget -> create budget -> use Template -> choose any templet like 'Zero spend budget' -> add email -> create budget
### How To Create Customize Budgets
- Here you can also add some action when budget surpasses some limit
- Creating a budget => Billing and cost management -> Budget -> create budget -> Customize Budgets -> budget name -> Recurring budget --> Enter your budgeted amount ($) ->next -> configure alerts -> you can add more then 1 alerts and more then 1 actions -> Review -> create budget
